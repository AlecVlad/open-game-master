## Ограничения

- После слияния 0.35.1 TypeScript, lint, production build, i18n-тесты и браузерные сценарии **не запускались**. Наличие коммита не означает успешную сборку.
- Перевод новых интерфейсных потоков не считается завершённым только потому, что в проекте есть ключи или код i18n.
- Старые API-контракты и технические идентификаторы менять только при необходимости; пользовательские данные и игровой контент не переводить автоматически.
- `/privacy` и `/terms` исключены из объёма игровой локализации.
- Этот документ — единственная рабочая сводка; новые checkpoint-файлы не создавать.
