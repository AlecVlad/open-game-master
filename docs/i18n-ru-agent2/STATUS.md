### Блок 3 — персонажи и кампании
- На главной странице локализованы отказы входа по коду комнаты и быстрого старта: неверный/неизвестный код, завершённая или уже начавшаяся кампания, отсутствие мест, ограничение частоты попыток, отсутствие рассказчика и запрет создания кампаний. API добавляет стабильные `errorCode` и параметры, сохраняя старый `error`; компоненты `JoinCard` и `StarterDialog` переводят ответы через `refusalText`.
- Ошибки удаления и копирования кампаний в домашнем списке также проходят через `refusalText`. API сообщает коды запрета удаления не владельцем, отсутствия доступа к источнику копирования и неверного запроса; EN/RU-ключи добавлены.
- В мастере создания кампании передан словарь переводов в импорт материалов из Workshop, поэтому отказы импорта больше не подставляются в итоговый текст на английском. Ошибки чтения, сохранения и удаления пользовательских настроек по умолчанию переведены; API возвращает `INVALID_CAMPAIGN_DEFAULTS` для некорректного формата, прежний текст `error` сохранён. Добавлены проверки переводов и статическая сверка плейсхолдеров.
- Повторная генерация портретов в списке библиотеки и на странице персонажа теперь переводит отказ API через `refusalText`. API отдаёт `CHARACTER_NOT_FOUND` и `PORTRAIT_NO_IMAGE_MODEL`; последний объясняет по-русски, что на сервере нет модели изображений и можно загрузить портрет вручную. Проверены также соседние операции клонирования и импорта: их ошибки уже проходят через структурированный отказ. EN/RU-ключ и плейсхолдеры сверены; `test-i18n.mjs` дополнен проверкой нового кода. Тесты проекта не запускались.
- Диалог «Использовать персонажа в кампании» больше не выводит английский текст API без обработки: известные отказы проходят через `refusalText`. Добавлены стабильные коды и EN/RU-пары для ограничений спутников, заполненной группы, уже присоединившегося/ушедшего спутника, отсутствующего спутника в библиотеке, неверного листа и запрета мультиклассирования. В `instantiateIntoCampaign` добавлены коды для отсутствующего персонажа, неверной роли и занятого места. Старые поля API сохранены; `test-i18n.mjs` проверяет переводы, параметры и коды. Статическая сверка новых плейсхолдеров EN/RU пройдена; тесты проекта не запускались.
- Проверены лист персонажа, повышение уровня, мультиклассирование, стартовое снаряжение, каталог, черты и заклинания; мастер кампании, настройки, лобби, приглашения, присоединение, библиотека и выбор персонажа.
- Динамические блокировки конструктора персонажа, стартового снаряжения, требований черт, мультиклассирования, валидации и присоединения переведены по кодам/параметрам. Старые поля API сохранены для совместимости.
