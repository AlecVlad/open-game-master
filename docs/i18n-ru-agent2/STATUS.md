## Как обновлять статус

1. При начале работы указать конкретный подраздел и список проверяемых компонентов.
2. После выполнения отмечать только реально проверенные пункты.
3. Когда все критерии блока из `PLAN.md` выполнены, создать соответствующий пустой файл-флаг в этой папке.
4. После создания флага изменить состояние блока здесь на **Завершён** и добавить дату/коммит, подтверждающий результат.
5. Если обнаружена регрессия или критерии больше не выполняются, удалить флаг и вернуть блоку статус **Не завершён**.
